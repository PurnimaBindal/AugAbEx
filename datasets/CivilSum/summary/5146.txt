Punjab Civil Service Rules, Vol. II, Rule 5.82 (c)(1) - Compulsory retirement without pension - Pension - Delay - Void orders - Limitation - If an order of compulsory retirement without pension is not challenged within the time limit, the retiree cannot claim pension, even if there is no time limit set for pension matters - The retiree cannot simply allege the order to be void and ignored - The order must be set aside before any action can be taken.
