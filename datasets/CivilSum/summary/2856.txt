According to the Jammu and Kashmir Limitation Act's Sections 3 and 5, along with the Civil Procedure Code, 1908's Section 96, Order 9, Rule 13, Order 43, Rule 1, and Order 43(d), if an application for condonation is dismissed, then the application under Order 9, Rule 13 is also dismissed; resulting in an appeal being allowed under Order 43(d) of the Code.
